QuotaVadis 0.2.0

• New look: glass cards per tool, glowing gradient bars, rounded cost chart. Same simple panel.
• Settings ▸ Menu Bar: choose which windows count toward the “Highest usage” number.
• Limits refresh every minute by default; 30-second option.
• Extra usage alerts (Claude) and a “Send test notifications” button; iCloud “Sync now” and clear sync status.
• Reliability: a stuck tool no longer blocks the others or the iCloud publish; the Codex helper is cancelled cleanly; turning sync off waits for in-flight writes; CloudKit calls have timeouts; measurement age travels with the data so the iPhone and widgets can show Stale honestly.
• Codex model-specific limits (e.g. Spark) count toward the highest usage and alerts even when compact.
