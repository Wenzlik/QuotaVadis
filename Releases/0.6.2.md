QuotaVadis 0.6.2

• Widgets got a visual refresh: glowing usage bars with pace markers, provider icons and a clearer text hierarchy, matching the menu bar panel.
• macOS widgets use the extra room: the large overview shows three windows per provider and full reset times (e.g. "3d · Sun 21:00"); the medium overview shows reset clock times too. iPhone widgets keep a compact layout that no longer overflows with four providers.
• Large widget: Claude no longer briefly appears twice on load.
• Widgets no longer get stuck showing stale data or an old layout after an update — the widget extension restarts when its version doesn't match the app.
• Widget gallery: black previews fixed. Desktop widgets show clearer empty / duplicate-app diagnostics, and there are new Quota pace widgets.
• New optional Observatory visual theme (Settings → Visual theme), off by default — a deep-space / aurora look.
