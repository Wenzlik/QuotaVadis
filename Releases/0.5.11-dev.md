QuotaVadis 0.5.11-dev (Development channel — experimental)

• Menu bar (experimental "Direction A"): each provider is a round 18 pt badge with a dark centre and white digits; usage colour moved to a proportional arc on the rim, so the number keeps the same contrast at any percentage. Missing data shows "–" instead of looking like 0.
• Stronger monochrome vendor marks; the short-window (5h) mark stays slightly smaller.
• Stale indicator dot no longer clipped at the right edge.
• Settings ▸ Appearance ▸ Menu bar (Filled bars) has a "Bar look" choice: Circular (these round badges, default) or Classic (the 0.5.6 capsule pills). The menu bar and the preview switch instantly; the choice is remembered. Czech labels: Kruhové / Původní.
• Only offered on the Development update channel (Settings ▸ Updates). Stable users stay on 0.5.10.
