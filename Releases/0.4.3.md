QuotaVadis 0.4.3

• Another pass at the Keychain password prompt, this time with a second, independent review of the code. Background refresh now reuses the last successfully read token from memory instead of asking the Keychain again every time — a real Keychain read now happens roughly once per token lifetime, not once per refresh, which should make an unprompted prompt effectively impossible.
• Fixed a real bug found along the way: an unexpected (not just "locked") response from the pre-check was being treated as "safe to proceed" instead of "play it safe" — the most likely actual cause of the prompt some of you saw overnight in 0.4.2.
