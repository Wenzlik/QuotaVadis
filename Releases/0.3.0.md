QuotaVadis 0.3.0

• Works without Claude Code. Claude limits can come from your claude.ai session: the Claude desktop app and Chrome are read automatically, or paste the sessionKey in Settings ▸ Claude. Every organization with limits gets its own row; with Claude Code present, only organizations it does not cover are added.
• Command line: `quotavadis` in Terminal shows the same limits (table, --json, --watch, --provider, cost). Install the link from Settings ▸ General.
• Cursor’s Grok Bot appears in the main list as soon as it has been used.
