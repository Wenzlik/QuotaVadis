QuotaVadis 0.5.0

• QuotaVadis can now sign in to Claude on its own: Settings ▸ Claude ▸ “Sign in to Claude…”. The login is kept in QuotaVadis's own Keychain item, so macOS stops asking for permission — every other source borrows an item another app owns, and Claude Code replaces its item whenever it refreshes its token, which throws away the permission you granted. It also works when Claude Code isn't installed at all.
• Without signing in, the Keychain prompt still gets far rarer. Opening the panel no longer reads Claude Code's item — it used to, every time the numbers were more than 30 seconds old — and the token is now remembered across quits, reboots and updates instead of being fetched again on every launch.
